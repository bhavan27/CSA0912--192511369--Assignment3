# Task 01 – ATM Exception Handling
Compile/run from repository root:
`javac -d Task01/out Task01/src/AtmDemo.java`
`java -cp Task01/out AtmDemo`
Includes five failure/success paths, multi-catch, ordered catch blocks, finally and a caught stack-trace demonstration. `output/` contains illustrative sample output; run locally to create machine-specific evidence.

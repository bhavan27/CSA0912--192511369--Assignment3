# Task 04 – Thread Creation and Life Cycle
Compile/run: `javac -d Task04/out Task04/src/ThreadStationsDemo.java` then `java -cp Task04/out ThreadStationsDemo`.
Includes extending Thread, implementing Runnable, start/sleep/join/isAlive, direct run(), ten finish-order trials and a fixed-thread-pool alternative. Output order is scheduler-dependent; rerun to record your own ten trials.
